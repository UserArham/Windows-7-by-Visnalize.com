=========================================================
           MICROSOFT WINDOWS 7 ULTIMATE (x86)
=========================================================

VERSION: Windows 7 Ultimate
ARCHITECTURE: x86 (32-bit)
EDITION: Ultimate
RELEASE DATE: October 22, 2009

=========================================================
SYSTEM REQUIREMENTS
=========================================================
Minimum:
- Processor: 1 GHz or faster 32-bit (x86)
- RAM: 1 GB
- Hard Drive: 16 GB free disk space
- Graphics: DirectX 9 compatible with WDDM 1.0 driver
Recommended:
- Processor: 2 GHz or faster
- RAM: 2 GB or more
- Hard Drive: 20 GB or more free disk space
- Graphics: DirectX 10 compatible

=========================================================
INSTALLATION NOTES
=========================================================
1. Backup all important files before installation.
2. Insert the installation DVD and boot from it.
3. Follow the on-screen instructions to perform a clean install or upgrade.
4. Installing the latest Service Pack (SP1) is strongly recommended.
5. Ensure drivers for network, graphics, and audio devices are installed after setup.

=========================================================
FEATURES
=========================================================
- Complete Windows 7 features: Home Premium + Professional
- Aero Glass UI with enhanced visual effects
- Windows Media Center
- BitLocker drive encryption
- Multilingual User Interface (MUI)
- Remote Desktop Host (connect to this PC remotely)
- Domain join, Group Policy, and Encrypting File System (EFS)
- Windows Update support (security updates ended January 14, 2020)
- Backward compatibility with most 32-bit applications

=========================================================
USAGE NOTES
=========================================================
- Designed for users who require all Windows features on 32-bit hardware.
- Maximum usable RAM: ~3.2 GB due to 32-bit architecture.
- Performance may be limited on systems with heavy multitasking or high-memory applications.
- Antivirus and firewall software recommended for online usage.
- Upgrades from older Windows versions (XP, Vista) require clean installation in most cases.
